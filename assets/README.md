# Assets Folder

Please add the following images to this folder:

## Logo Files (assets/logos/)
- **aathiksh_logo.jpeg** - Main Aathiksh AutoMart logo (shield with two-tone car)
  - Recommended size: 512x512px or higher
  - Format: PNG with transparent background

## Image Files (assets/images/)
- **car_interior.jpg** - Car interior image (Suzuki steering wheel) for login screen
  - Recommended size: 1200x800px or higher
  - Format: JPG
  
- **dashboard_car.jpg** - Toyota Fortuner SUV image for dashboard hero section
  - Recommended size: 1920x1080px or higher
  - Format: JPG
  
- **analyze_car_bg.jpg** - Mahindra Thar SUV image for analyze car screen
  - Recommended size: 1200x800px or higher
  - Format: JPG
  
- **inventory_car.jpg** - Jeep Wrangler Rubicon image for inventory screen
  - Recommended size: 1200x800px or higher
  - Format: JPG

## Notes
- All images should be optimized for web use
- The app will gracefully handle missing images by showing fallback icons
- Logo should have transparent background for best appearance
